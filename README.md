# Vanta

> A Clean, Powerful Launcher That Blends Productivity

A brutalist Android launcher replacement inspired by Windows Phone 8.1 / Lumia Metro UI. Built with Kotlin + Jetpack Compose.

**Developer:** [@ftwsourav](https://github.com/ftwsourav)

---

## Download

Download the latest APK from the [Releases page](https://github.com/ftwsourav/vanta-launcher-public/releases).

1. Download `Vanta-v4.1.apk` from the latest release
2. Install on your Android phone (Android 11+)
3. Set as default launcher

## Features

### Home Screen
- **Live Tiles** — every tile cycles through frames with Lumia-style 3D Y-axis flip
- **Music Widget** — album art, transport controls, 5-bar visualizer
- **Tasks & Notes Widgets** — todo list + quick notes on home
- **Battery Tile** — animated count-up percentage
- **People Hub** — contacts with avatars, tap to dial
- **Weather Tile** — real Open-Meteo data, 3-day forecast
- **Quick Settings FAB** — WiFi/BT/DND/Night toggles

### Tile Management
- Drag-to-reorder + drag-to-resize in edit mode
- 4 tile sizes: SMALL, MEDIUM, WIDE, LARGE
- Tile groups with named headers
- Long-press context menu

### Navigation
- 3-page pivot: Home / Apps / Focus
- Edge swipe gestures
- 5 smoothness presets (SNAPPY/SMOOTH/LUXURIOUS/BOUNCY/GLASS)

### Apps Drawer
- Alphabetical with letter scrubber
- Semantic zoom (pinch to A-Z grid)
- WP-style app bar

### Focus Mode
- Stopwatch with progress ring + laps
- Productivity app suggestions
- Quick notes

### Design
- 6 themes + dark mode
- Time-of-day palette tint
- Icon theming (6 styles)
- Wallpaper background option
- Parallax + drifting noise overlay
- Space Grotesk + JetBrains Mono
- 120fps support

### Motion
- Cinematic intro splash
- Glance screen
- Turnstile app transition
- Spring animations throughout

## Requirements

- Android 11+ (API 30)
- Works best on 120Hz displays (OnePlus 13, etc.)
