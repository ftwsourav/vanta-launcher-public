# VANTA

### A Clean, Powerful Launcher That Blends Productivity

A brutalist Windows Phone Metro-inspired Android launcher built with Kotlin + Jetpack Compose. Live tiles, pivot navigation, accent colors, and a 4-page productivity workflow: **Home · Apps · Focus · Live**.

## Download

👉 **Latest APK:** [Releases](https://github.com/ftwsourav/vanta-launcher-public/releases)

1. Download the APK from the latest release
2. Enable "Install unknown apps" for your browser
3. If Google Play Protect blocks install: **Play Store → Profile → Play Protect → Settings → Turn off Scan apps**
4. Install → Set as default launcher

## Features

- **Brutalist Metro UI** — Windows Phone 8.1/10 Lumia aesthetic, live tiles, pivot navigation
- **4-Page pivot** — Home · Apps · Focus · Live (swipe + tap navigation)
- **Live tiles** — flip animations, random timing, weather, clock, battery, music
- **Smart Live page** — big clock, now-playing, battery, next alarm, real notifications (tap to open+clear, mute per app, grouping)
- **Focus mode** — stopwatch, quick timers, quick notes, productivity suggestions
- **Customization** — 48 accent colors, 6 themes, Material You dynamic color (Android 12+), wallpaper presets, status bar control
- **Productivity** — Recents app switcher, Quick Settings panel, app shortcuts, notification badges, dock-free clean Home
- **Performance** — 5 smoothness presets, 120fps target, silky pager, slideable home, motion touch
- **Backup/Restore** — export/import all settings as JSON
- **First-run onboarding** — 3-slide tutorial

## Tech

- **Kotlin** + **Jetpack Compose** (Material 3)
- **Min SDK 30** (Android 11), **Target SDK 35** (Android 15)
- **Compose BOM 2024.12**
- **Build:** Gradle 8.9, JDK 17
- **Single activity** · Compose-only UI · ViewModel + StateFlow
