## About

**Vanta** is a brutalist Android launcher inspired by the Windows Phone 8.1 / 10 Lumia Metro UI. It blends the classic live-tile aesthetic with modern productivity features — built for daily-driver use on any Android 11+ device, from a 60Hz budget phone to a 120Hz flagship to a foldable tablet.

Four pivot pages: **Home**, **Apps**, **Focus**, **Live**. Swipe or tap to navigate. Every tile is alive.

## Features

### Core
- **Brutalist Metro UI** — Windows Phone Lumia aesthetic, live tiles, pivot navigation
- **4-page pivot** — Home / Apps / Focus / Live (swipe + tap navigation)
- **Live tiles** — flip animations, random timing, weather, clock, battery, music
- **Smart Live page** — big clock, now-playing, battery, next alarm, real notifications (tap to open + clear, mute per app, grouping)
- **Focus mode** — stopwatch, quick timers, quick notes, productivity suggestions

### Personalization
- **48 accent colors** + 6 themes
- **Material You** dynamic color (Android 12+) — whole theme follows wallpaper
- **Auto dark mode** — follows system, or sunset/sunrise, or manual
- **Auto refresh rate** — device-best by default (60/90/120Hz auto)
- **Wallpaper presets** — 6 built-in gradients
- **Status bar customization** — show / transparent / icon color
- **Icon pack support** — Lawnicon format
- **Backup / Restore** — export + import all settings as JSON

### Productivity
- **Recents app switcher** — Lumia-style card list, swipe to kill
- **Quick Settings panel** — WiFi / BT / DND / Flash / Rotate / Brightness / more
- **App shortcuts** — long-press for system shortcuts + app info + uninstall
- **Notification badges** — unread count per app on tiles
- **Web search + history** in swipe-down search
- **Most used + recently used** sections in drawer

### Performance & Polish
- **5 smoothness presets** — silky pager, slideable home, motion touch
- **Tablet + foldable** adaptive layouts (4 / 5 / 6 columns)
- **First-run onboarding** — 3-slide tutorial
- **Hindi + Spanish** localization
- **TalkBack accessibility** — content descriptions on all tiles
- **Haptics** throughout
